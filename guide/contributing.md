# Contributing

## Issues and discussions

* To report a bug or a documentation error, [open an issue][open-an-issue].
* To ask a question or share an idea, [start a discussion][start-a-discussion].

## Pull requests

For pull requests, follow these guidelines:

* Use `master` as the base branch.
* To format your code, use [`ktfmt`][ktfmt] with `--google-style`. For matters not handled thereby, follow the conventions described on the [“Coding conventions”][coding-conventions] page of the Kotlin documentation.
* Add documentation for all public API elements.
