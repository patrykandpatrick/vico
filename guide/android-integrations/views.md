# Views

[Android is now Compose-first.][android-is-now-compose-first] Vico’s `views` module remains available but, [like the official view-based Jetpack libraries][like-the-official-view-based-jetpack-libraries], will receive only critical fixes. [Read the `views` guide.][read-the-views-guide]

If your project will stay view-based for the foreseeable future and you need the latest Vico features, you can use the `compose` module with [`ComposeView`][compose-view].
